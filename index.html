Bước 1: Tạo Cloudflare Worker làm Proxy (Bắt buộc để vượt lỗi CORS)

Vì trình duyệt chặn các request trực tiếp đến domain khác (CORS) và không cho tự set Cookie, bạn cần tạo 1 Cloudflare Worker làm trung chuyển (hoàn toàn miễn phí):

  1. Truy cập Cloudflare Dashboard và đăng nhập (hoặc đăng ký miễn phí).
  2. Chọn Workers & Pages -> Click Create application -> Create Worker.
  3. Đặt tên cho Worker của bạn (ví dụ: truyen-proxy) rồi bấm Deploy.
  4. Sau khi deploy, bấm vào nút Edit code.
  5. Copy toàn bộ đoạn code dưới đây và dán đè vào file worker.js trong giao diện Cloudflare:

  1. Bấm nút Save and deploy ở góc trên bên phải màn hình Cloudflare.
  2. Copy đường dẫn URL của Worker (ví dụ: https://truyen-proxy.account.workers.dev) và dán vào ô Địa chỉ CORS Proxy trên giao diện web này.

Bước 2: Cách lấy Cookie từ trình duyệt

  1. Truy cập trang web truyenhdc.com và đăng nhập tài khoản của bạn.
  2. Nhấn phím F12 (hoặc chuột phải -> Inspect / Kiểm tra) để mở DevTools.
  3. Chuyển qua tab Application (trên Chrome/Edge) hoặc tab Storage (trên Firefox).
  4. Ở menu bên trái, tìm mục Cookies và chọn https://truyenhdc.com.
  5. Tìm Cookie có tên bắt đầu bằng wordpress_logged_in_...:
    • Copy tên đó (ví dụ: wordpress_logged_in_fc056e1f7bf1317b0c2c528e1dc3e0ac) dán vào ô Tên Cookie.
    • Copy giá trị dài ngoằng của Cookie đó dán vào ô Giá trị Cookie.

Bước 3: Deploy web lên GitHub Pages

  1. Tạo một repository mới trên GitHub và upload các file (index.html, style.css, app.js) lên.
  2. Vào mục Settings của repository -> Chọn Pages ở menu bên trái.
  3. Tại phần Build and deployment, chọn Branch là main (hoặc master) và folder là / (root), sau đó bấm Save.
  4. Chờ 1-2 phút, GitHub sẽ cung cấp cho bạn một link web tĩnh (ví dụ: https://username.github.io/repo-name/) để sử dụng online bất kỳ lúc nào!
